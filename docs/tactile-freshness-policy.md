# Sharpa触觉新鲜度开关（2026-11-07）

## 使用

仓库的 `configs/sharpa.yaml` 显式设置 `tactile_freshness_check: false`。只针对Sharpa的20路触觉（左右手各5指，每指形变/力矩）关闭样本过旧造成的输出无效门控。需要恢复严格检查时改为 `true`，正常停止任务、等待作业收尾后再启动。布尔字符串等无效配置会报错。

默认关闭时，30Hz输出保持因果取样：当前网格行选择最近且不晚于它的真实样本，允许其年龄超过默认150ms；样本值可能重复，不插值、不推测或重写时间。独立逐行来源校验继续检查所选值完全相等及不存在未来样本。报告的 `alignment.tactile_freshness` 保存开关、门槛、每通道过旧帧数、不可用帧数和实际最大年龄。

仍要求通道存在、有样本、正确类型、有效形状/图像编码、有限力矩。首条真实样本之前不能用未来帧补值，仍裁去无效边缘；完全缺失不伪造零值。深度、RGB、关节、命令、接管状态及静止清洗条件不变。该开关不撤销采集端collection_state的失败记录，也不是跳过文件结构、消息计数或来源哈希校验。
